# AI资源比价网站

一个类似 PriceAI 和一可比价网的AI资源比价平台。

## 技术栈

- Next.js 14 + React + TypeScript
- Tailwind CSS + Radix UI
- PostgreSQL + Prisma ORM
- Cloudflare Pages

## 快速开始

```bash
npm install
npm run db:generate
npm run db:push
npm run dev
```

## 部署

推送到 GitHub 后，Cloudflare Pages 会自动部署。
